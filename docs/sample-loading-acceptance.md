Test suites below are complementary and overlap. A row records concrete cases,
not exhaustive validation of every WAV layout or floating-point bit pattern.
The decoder intentionally accepts a restricted WAV subset.

The new loaded-sampler suite passes locally in debug and release. The local full
check passes with 85 headless, 90 workspace, eight decoder/bank memory, 15 audio
instrumented and 13 frontend tests, plus nine CLI scenarios; these suites overlap.
Windows debug desktop build without an installer also passes. Existing
reader, bank, fault, memory and CLI suites are selected by the regular checks;
their earlier release measurements remain dated in the linked reports. No
dependency, generated DTO, public API or musical behavior changes in 9.3.e.

Not established by this matrix: process RSS, physical disk failures/OOM, universal
WAV-player compatibility, arbitrary concurrent file rewrites with unchanged
length, interruption of blocked OS I/O, or every scheduler interleaving. Native
sampler callback allocation/deadlines, hardware playback, physical disconnect,
Linux native and macOS remain unverified. The existing sine evidence does not
validate a native sampler. Hosted CI for the local 9.3 changes remains pending
publication and inspection of its exact revision.
